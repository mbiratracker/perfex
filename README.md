## 📋 Description

**Perfex CRM** est une application web complète de gestion de la relation client (CRM) conçue pour les entreprises souhaitant centraliser et optimiser leurs opérations commerciales.

### 🚀 Fonctionnalités principales

- **Gestion des clients** : Suivi complet des informations clients et prospects
- **Facturation** : Création et gestion de devis, factures et paiements
- **Gestion de projets** : Suivi des projets, tâches et délais
- **Support client** : Système de tickets et base de connaissances
- **Rapports** : Tableaux de bord analytiques et statistiques avancées
- **Gestion des contrats** : Suivi des contrats et signatures électroniques
- **Planning** : Calendrier partagé et gestion des rendez-vous
- **Workflows automatisés** : Email templates et automatisations

### 🛠 Technologies utilisées

- **Backend** : PHP 7.4+ (CodeIgniter 3)
- **Base de données** : MySQL 5.7+ / MariaDB 10.2+
- **Frontend** : HTML5, CSS3, JavaScript, jQuery, Bootstrap 4
- **Serveur** : Apache/Nginx
- **Versionnement** : Git & GitHub

## 📦 Installation

### Prérequis

- PHP 7.4 ou supérieur
- MySQL 5.7 ou supérieur
- Apache/Nginx
- Extensions PHP : mysqli, pdo, gd, zip, mbstring
